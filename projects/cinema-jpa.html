Cinema JPA.

Application Java permettant de modéliser, importer, persister et interroger des données cinématographiques structurées autour de plusieurs entités et relations JPA.

Java 21 JPA / Hibernate MariaDB JPQL Maven JUnit
Voir le dépôt GitHub ↗
01 / Contexte & objectif

Transformer plusieurs sources CSV en un modèle métier exploitable.

Le projet s'appuie sur plusieurs jeux de données liés au cinéma : films, acteurs, réalisateurs, pays, langues, genres, rôles et lieux. Le travail consiste à reconstruire les relations entre ces données, puis à les persister dans une base relationnelle.

Java 21langage principal
JPAmapping objet-relationnel
11tests automatisés
02 / Modélisation du domaine

Structurer les entités, l'héritage et les relations.

Le modèle comprend notamment Film, Personne, Acteur, Réalisateur, Rôle, Genre, Langue, Pays, LieuNaissance et LieuTournage. Personne factorise les informations communes aux acteurs et réalisateurs, tandis que Rôle porte la relation entre un film, un acteur et un personnage.
