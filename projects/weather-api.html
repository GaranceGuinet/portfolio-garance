01 / Objectif & périmètre

Exposer des données météo via une API REST structurée.

L'API permet de consulter les relevés, les villes disponibles, les données d'une ville, des statistiques et l'état du service. Le projet couvre également la validation, les erreurs, la documentation et le stockage CSV. Les données sont chargées en mémoire au démarrage, puis le fichier est réécrit lors des modifications.
